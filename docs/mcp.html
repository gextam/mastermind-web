Overview

The Mastermind server is one Node.js process with no dependencies. It serves the browser game, a REST API under /api, and an MCP server at /mcp using the Streamable HTTP transport, so any MCP client (Claude Code, Claude Desktop, claude.ai custom connectors, the MCP Inspector, your own agent) can connect over the network and play. A stdio bridge is included for clients that launch servers as local commands. Every player, human or agent, plays on the same scoreboard.

Codebreaker

new_game hides a random code; the agent calls guess until the key pegs are all black or the guesses run out. Lower guess counts score higher.

Codemaker

new_game with mode: "maker" and a secret: the server's Knuth minimax solver breaks the code and the transcript comes back at once. Points = guesses the solver needed.

Scoreboard

get_scores returns top scores, codemakers, per-player statistics and recent games; pass player for one player's own record.

Same catalog everywhere

The MCP tools and the REST routes are generated from one catalog with one validator: identical arguments, identical JSON, identical error codes.

Quick start

1. Run the server

git clone https://github.com/gextam/mastermind-web.git
cd mastermind-web
node server/server.js            # game http://localhost:8772/  ·  MCP http://localhost:8772/mcp

# or, on Windows, double-click start.cmd

Node.js 20 or newer, nothing to install. The data file server/data/state.json is created on first use.

2. Connect a client

Claude Code (remote, Streamable HTTP)

claude mcp add --transport http mastermind https://cocojs.com/games/mastermind/mcp
# with an API key configured on the server:
claude mcp add --transport http mastermind https://cocojs.com/games/mastermind/mcp --header "Authorization: Bearer YOUR_KEY"

Claude Desktop (stdio bridge in claude_desktop_config.json)

{
  "mcpServers": {
    "mastermind": {
      "command": "node",
      "args": [
        "/path/to/mastermind-web/server/mcp-stdio.js",
        "--url",
        "https://cocojs.com/games/mastermind/mcp"
      ]
    }
  }
}

The bridge forwards every message to the HTTP server so Desktop plays on the shared scoreboard. Pass --local instead of --url to play entirely in-process with a private data file (no server needed), or add --api-key=… when the server requires one.

claude.ai custom connector

Settings → Connectors → Add custom connector → URL https://cocojs.com/games/mastermind/mcp. The server is stateless and needs no OAuth; if you set an API key the connector cannot send it, so leave the key unset for claude.ai or put the server behind your own gateway.

MCP Inspector

npx @modelcontextprotocol/inspector
# transport: Streamable HTTP · URL: https://cocojs.com/games/mastermind/mcp

3. Say the word

“Play a game of Mastermind as Claude on the classic board. Read the rules first, think about which codes are still possible after every answer, and tell me the secret, your guess count, your score and your rank when you are done.”

There is also a ready-made prompt, play, that says exactly that (see prompts), and node tools/play-demo.js plays a game through the MCP endpoint from the command line so you can watch the transcript.

A game, call by call

agent → server tools/call rules (once; notation, boards, scoring) agent → server tools/call new_game {player, preset} → game_id, palette, guesses_left, message agent → server tools/call guess {game_id, "RROO"} → feedback {black, white}, history, guesses_left agent → server tools/call guess … → … (keep only codes consistent with every answer) server → agent status "won" | "lost", secret, score (the secret is revealed only when the game is over) agent → server tools/call get_scores {player} → rank, statistics, recent games

Games have no session: the game_id is the only handle, so an agent can stop and resume from any client. Unfinished games expire after 24 hours of inactivity; finished games remain readable through get_game and in the scoreboard.

Tools

Every tool returns the result both as a JSON text block and as structuredContent. Validation and game errors come back as a tool result with isError: true and a message such as Error (game_over): …; protocol-level problems (unknown tool, malformed request) are JSON-RPC errors.

new_game POST /api/games

Start a new game. Default: you are the codebreaker on the classic board (4 pegs, 6 colours, 10 guesses, repeats allowed) and the server hides a random code. Pass preset or the individual settings for other boards. With mode "maker" you supply the secret instead and the server's Knuth solver tries to break it; the game is returned already finished with the solver's transcript and your codemaker points. Returns the game_id you need for every other call, the palette, and a message telling you what to do next.

ArgumentTypeRequiredDescription
playerstringnoYour name on the scoreboard (default "Anonymous")
max length 24
modestringnobreaker: you guess the server's code (default). maker: you set the code, the server's solver breaks it.
one of breaker, maker
presetstringnoBoard preset: classic (4 pegs · 6 colours · 10 guesses); mini (3 pegs · 6 colours · 8 guesses); unique (4 pegs · 6 colours · no repeated colours); blanks (4 pegs · 6 colours + empty · 12 guesses); super (5 pegs · 8 colours · 12 guesses); grand (6 pegs · 8 colours · 15 guesses)
one of classic, mini, unique, blanks, super, grand
pegsintegernoPegs in the code (overrides the preset)
min 2 · max 8
colorsintegernoNumber of colours in play (the first N of the palette)
min 2 · max 10
max_guessesintegernoGuesses allowed
min 1 · max 30
allow_duplicatesbooleannoMay the code repeat a colour? (default true)
allow_blanksbooleannoMay the code contain empty positions? (default false)
secretstring | arraynomaker mode only: the code the solver must break. A code: an array of colour names, letters or numbers (["red","green","blue","yellow"], ["R","G","B","Y"], [1,4,5,3]) or a string of letters/digits ("RGBY", "1453"). Letters: R red, O orange, Y yellow, G green, B blue, P purple, W white, K black, C cyan, N pink; "." is empty when blanks are allowed.

guess POST /api/games/{game_id}/guess

Submit a guess for a game you are breaking. Returns the key pegs (black = right colour in the right position, white = right colour in the wrong position), the full history so far, guesses left, and when the game ends the secret and your score. A guess must have exactly as many pegs as the code.

ArgumentTypeRequiredDescription

max length 40
guessstring | arrayyesA code: an array of colour names, letters or numbers (["red","green","blue","yellow"], ["R","G","B","Y"], [1,4,5,3]) or a string of letters/digits ("RGBY", "1453"). Letters: R red, O orange, Y yellow, G green, B blue, P purple, W white, K black, C cyan, N pink; "." is empty when blanks are allowed.

Notation & boards

A code is a list of colours. A guess (or a codemaker secret) may be sent as an array of names, letters or numbers, or as one string of letters or digits; the server echoes codes back as colors (names), letters and ids. A game uses the first colors entries of the palette:

1 red R2 orange O3 yellow Y4 green G5 blue B6 purple P7 white W8 black K9 cyan C10 pink N

With allow_blanks the extra symbol empty (0, .) may appear in codes.

Feedback. black = pegs of the right colour in the right position, white = pegs of the right colour in the wrong position. They are counts, not positions, and each secret peg and each guess peg is matched at most once: against the code RGBY, the guess RRRR earns 1 black and 0 white.

Scoring

Codebreaker: score = round(1000 × (max_guesses + 1 − guesses_used − hints_used) ÷ max_guesses × difficulty), where difficulty = ln(code_space) ÷ ln(1296) (classic = 1.00, super ≈ 1.45, grand ≈ 1.74). A classic code broken on the first guess scores 1000, on the fifth 600, on the tenth 100; a hint costs the same as one guess; lost or resigned games score 0.

Codemaker: points = the guesses the solver needed, +1 if it never broke the code. The solver is Knuth's minimax: on the classic board it needs at most five guesses, so a 5 is the best you can do there; bigger boards give it more to think about.

The scoreboard ranks codebreaker wins by score, then by time; players aggregates games, wins, win rate, average guesses on wins, best and total score; codemakers ranks by points.

Playing well

  1. Open with two pairs (RROO on the classic board). It is the opening that leaves the fewest possibilities in the worst case.
  2. Keep the consistent set. After each answer, discard every candidate code that would not have produced exactly that black/white answer against your guess. Only codes that survive every answer can be the secret.
  3. Guess a survivor, or better, the guess (survivor or not) whose worst-case answer leaves the smallest consistent set. That is Knuth's rule and it solves the classic board in five.
  4. Ask for a hint only when stuck: hint returns the size of the consistent set, a sample and the solver's next guess, but costs a guess in the score.
  5. Read message. Every response says what to do next and, at the end, the secret and your score.

             MASTERMIND_ALLOWED_ORIGINS, MASTERMIND_PUBLIC_URL
ConcernBehaviour
AuthenticationNone by default. With --api-key, /mcp and the game routes require Authorization: Bearer <key> (or X-Api-Key); /api/health, /api/rules, /api/scores, /api/tools and the OpenAPI document stay public.
Origin policyBrowser requests to /mcp must come from the same host, from localhost, from the configured public URL or from --allowed-origins (DNS-rebinding protection). Non-browser clients send no Origin and are unaffected. CORS is open for the REST API.
Rate limitA token bucket per client address: bursts of 240 requests, refilling at 4 per second; excess requests get 429 with Retry-After. X-Forwarded-For is honoured when the connection comes from a private address (a reverse proxy).
PersistenceLive games and finished records are kept in one JSON file, written atomically and debounced. Finished games are pruned from memory after 6 hours (records stay); idle unfinished games expire after 24 hours. Records are capped at 20,000.
Reverse proxyMount under a prefix with --base-path (or MASTERMIND_BASE_PATH): the server strips it from every request, so ProxyPass /games/mastermind http://127.0.0.1:8772/games/mastermind in Apache (or location /games/mastermind/ { proxy_pass http://127.0.0.1:8772; } in nginx) just works. Set --public-url so the documents advertise the external address.
stdio bridgenode server/mcp-stdio.js --url https://cocojs.com/games/mastermind/mcp relays to a running server; --local runs the game in-process with --data (default server/data/state-stdio.json). Without --url it probes localhost:8772 and falls back to local play.

Protocol notes

  • Protocol versions 2025-06-18, 2025-03-26, 2024-11-05; the server echoes a supported requested version, otherwise answers with the newest.
  • Streamable HTTP, stateless: no Mcp-Session-Id is issued or required. POST /mcp answers with application/json (or text/event-stream when that is the only accepted type). Notifications and client responses get 202. GET /mcp returns 405 (no server-initiated stream); DELETE /mcp is accepted and a no-op. JSON-RPC batches are processed in order.
  • Capabilities: tools, resources (with templates, no subscriptions), prompts, logging. Tool results carry structuredContent plus a text block; tool annotations mark read-only and destructive tools.
  • Errors: -32700 parse, -32600 invalid request, -32601 unknown method, -32602 unknown tool / bad params, -32002 unknown resource.
